# Python Beginner Projects

Three small, well-commented Python projects — each one runs from the
command line with only the Python standard library (no installs needed).

| Project | Folder | What it does |
| --- | --- | --- |
| To-Do List | `todo-list-cli/` | Add, list, complete and delete tasks; saves them to `tasks.json` |
| Calculator | `calculator/` | Adds, subtracts, multiplies and divides; handles division by zero |
| Password Generator | `password-generator/` | Generates a random password (letters, digits, symbols) using `secrets` |

## How to run

```bash
python3 todo-list-cli/todo.py
python3 calculator/calculator.py
python3 password-generator/password_generator.py
```

Python 3 is the only requirement.
