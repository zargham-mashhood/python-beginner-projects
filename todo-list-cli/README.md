# To-Do List (CLI)

A simple command-line to-do list app written in Python.

## What it does

- Add tasks
- List tasks with done / pending marks
- Mark a task as done
- Delete a task
- Saves tasks to `tasks.json`, so they are still there next time you run it

## How to run

```bash
python3 todo.py
```

Then choose an option from the menu (1–5).

## What I learned

- Reading and writing JSON files
- Lists and dictionaries
- Loops and user input with basic error handling
