# Simple Calculator (CLI)

A small command-line calculator written in Python.

## What it does

- Adds, subtracts, multiplies and divides two numbers
- Handles division by zero with a friendly error message
- Re-asks until the user types a valid number

## How to run

```bash
python3 calculator.py
```

## What I learned

- Functions and a dictionary mapping operations to functions
- Input validation with `try` / `except`
- Handling edge cases (division by zero)
